# Repository guide for AI assistants

This repo is an **educational Reinforcement Learning curriculum** that grows
from a basic LunarLander DQN to Vision-Language-Action (VLA) models for robotics.

## Structure
- `rl/` — the importable library (the "professional codebase"). Agents in
  `rl/agents/`, shared parts in `networks.py`, `buffers.py`, `envs.py`,
  `utils.py`. Unified trainer + CLI in `rl/train.py`.
- `curriculum/00..07/` — numbered lessons. Each has a `README.md` (theory) and a
  Colab `notebook.ipynb` (regenerated by `tools/build_notebooks.py`).
- `scripts/` — `play.py` / `record.py` entry points.
- `legacy/` — the original single-file DQN, preserved unchanged for reference.
- `tests/` — `pytest` sanity checks.

## Conventions
- Keep each agent file readable and aligned with its lesson's maths; comments
  cite the update rules. Configs are `@dataclass`es.
- Standardize on **Gymnasium** (not old `gym`) and **LunarLander-v3**.
- If you change a lesson's code examples, regenerate notebooks:
  `python tools/build_notebooks.py`.

## Useful commands
```bash
pip install -e ".[box2d,dev]"          # install package + deps
pytest -q                              # run sanity tests
python -m rl.train --algo ppo --env LunarLander-v3 --save runs/ppo.pt
python scripts/play.py --algo ppo --model runs/ppo.pt
```

## Don't
- Don't reintroduce the old `gym` API or `v2` env ids.
- Don't add heavy deps to core `requirements.txt`; gate them behind extras.
