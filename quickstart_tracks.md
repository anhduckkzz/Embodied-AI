## How to study each track

For each notebook in a track:

1. Read the **Notebook type and ordered study structure** cell.
2. Run/read the scratch code.
3. Fill the **Scratch → framework mapping** table in your own words.
4. Write one paragraph about the **real-system role**.
5. Complete the mini-project or create your own equivalent.
